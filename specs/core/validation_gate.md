# VALIDATION GATE

## Level 0 Baseline Recovery
Recover standard exponential T1 decay.

## Level 1 Reduction Limit
Suppress nonlinear term and verify identical baseline behavior.

## Level 2 Convergence
Time step refinement  
Basis truncation refinement  
Sampling refinement where applicable  

## Level 3 Stability
Independent runs stable within measurement resolution.

## Level 4 Platform Comparison
Only after Levels 0 through 3 pass.

## Promotion Rule
Tier 2 requires at least one finalized run with all convergence checks pass.
