# System Boundary

## In scope

- QDP domain logic, runtime helpers, and module code
- program specs, configs, and validation scripts
- generated scientific artifacts needed for local review
- promotion artifacts that explain QDP's relationship to ALL-MIND

## Out of scope

- becoming part of the ALL-MIND core repo
- treating every generated output as a source document
- coupling QDP internals directly into ALL-MIND runtime code
- broad portfolio governance beyond the QDP integration surface

## Boundary rule

QDP remains a separate incubate repo until:

- its interface into ALL-MIND is explicit,
- the repo map is stable enough for repeat audits,
- the source-versus-generated boundary is cheaper to review.
