# Repo Map

- `modules/`: domain modules and runnable program pieces
- `runtime/`: runtime support code
- `config/`: configuration inputs
- `specs/`: scientific and operating specs
- `tools/`: supporting utilities
- `artifacts/`: generated outputs and reports
- `docs/`: supporting explanatory material
- `src/tdgl_rf/`: TDGL-RF runtime, CLI workflows, diagnostics, and analysis
- `validation/`: TDGL-RF validation manifests, thresholds, and frozen references
- `QDP_REPO_REFACTOR_PLAN.md`: structure and cleanup direction
- `qdp.py`: main repo-level entrypoint
- `qdp_validation.py`: legacy validation helper library retained for compatibility; not the primary repo entrypoint
