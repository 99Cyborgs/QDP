# Project Brief

MMM Studio is a typed metamaterial discovery and analysis workbench aimed at scientific software engineering, not demo theatrics.

Current repository priorities:

1. typed candidate and experiment registries
2. cross-reference validation with explicit issue reporting
3. baseline surrogate scoring with profile-aware ranking
4. reproducible run manifests, reports, and plots
5. clean extension points for simulation and RF workflows
