# E01 MM Failure Mode Ledger

| Rank | Mechanism | What it mimics | How to detect | How to mitigate | Decision gate affected |
| --- | --- | --- | --- | --- | --- |
| `1` | Equilibration lag | Apparent hysteresis caused only by insufficient dwell after field steps | Dwell-doubling changes `H_O`, `A_O`, or branch shape materially | Increase dwell until convergence or terminate the run as non-converged | `Gate 2: dwell validity` |
| `2` | Residual fridge field misestimation | False `ZFC` or false zero return, creating inherited loop offset | Zero-field checkpoints drift with nominal zero command; sign may depend on cooldown order | Re-null the field, document residual field estimate, repeat zero baseline before loops | `Gate 1: data completeness`, `Gate 3: H0 rejection` |
| `3` | Coil calibration error | Incorrect onset field, wrong branch scaling, or false asymmetry between positive and negative branches | Commanded field and calibrated field disagree, or witness onset shifts with recalibration | Recalibrate coil transfer before production loops and archive calibration metadata | `Gate 1: data completeness`, `Gate 5: geometry gate` |
| `4` | QP bursts | Step-induced loss and `T1` transients that look like retained memory | `T1` recovers with burst-like time dependence after field changes; residuals localize to step windows | Use selected-field `T1`, longer dwell, and burst rejection logic before scoring H1 | `Gate 4: H1 versus H3 versus H4 competition` |
| `5` | Readout nonlinearity | Apparent field dependence or loop area caused by measurement chain compression | Loss or frequency shift changes with readout tone placement or power even at fixed nominal settings | Lock linear-response point before loops and abort if drifted outside tolerance | `Gate 1: data completeness`, `Gate 3: H0 rejection` |
| `6` | Fabrication mismatch | False geometry ordering that looks vortex-specific | Same nominal widths differ in unrelated baseline parameters or lithographic metadata | Restrict H2 to same-chip matched geometries with documented fabrication parity | `Gate 5: geometry gate` |
| `7` | Cooldown contamination | Cooldown-specific trapped state or contamination interpreted as reproducible memory | One cooldown becomes an outlier in baseline, onset field, or witness coupling | Require minimum three cooldowns and do not promote on a single clean run | `Gate 1: data completeness`, `Gate 4: H1 versus H3 versus H4 competition` |
| `8` | Edge disorder and microstructure distortion | Width trend or field sensitivity that is geometric in appearance but not vortex-specific | Geometry ordering tracks fabrication roughness, not nominal width, across devices | Use same-chip matched widths and defer H2 if edge quality is not independently trusted | `Gate 5: geometry gate` |
