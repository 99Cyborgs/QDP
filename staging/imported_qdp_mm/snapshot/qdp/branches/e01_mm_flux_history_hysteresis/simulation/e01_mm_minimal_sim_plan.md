# E01 MM Minimal Simulation Plan

Use exactly the synthetic cases below. Do not add broader phase 1 simulation scope before these are complete.

| Synthetic case | Inputs | Outputs | Purpose | Failure pattern stressed |
| --- | --- | --- | --- | --- |
| `memoryless field loss with drift` | baseline scalar loss curve versus field, affine time drift, measurement noise, sham cadence | synthetic `1/Qi(B,t)`, `delta fr over fr(B,t)`, zero-field checkpoints | Verify that H0 plus allowed drift can explain non-memory data without being mistaken for H1 | false loop area generated by slow drift |
| `generic hidden state hysteresis` | two-state occupancy or retained-state surrogate, relaxation time, coupling amplitude, field-history path, measurement noise | hysteretic `1/Qi(B)`, `H_O`, `A_O`, cooldown-replicated loop traces | Test whether a minimal H1 model survives dwell and sham criteria while staying within the phase 1 parameter budget | underfitting a real metastable memory signal |
| `QP lag after field step` | step-triggered quasiparticle burst amplitude, recovery time, selected-field schedule, measurement noise | `T1(t)`, `1/Qi(t)`, apparent loop metrics reconstructed from finite dwell | Measure when H3 can fake primary hysteresis through lag rather than retained memory | transient lag misread as metastability |
| `fabrication noise false geometry signal` | nominal width list, random fabrication offsets, baseline-loss scatter, cooldown noise | synthetic geometry ranking of `H_O` and `delta fr over fr` | Estimate how easily false width ordering can appear without a vortex mechanism | spurious H2 gate pass from fabrication spread |
| `package common mode drift` | shared package drift trajectory, target gain, witness gain, timestamp grid, sham cadence | target and witness co-moving traces plus derived `H_O` and `A_O` | Validate that H4 can be identified and rejected using the required witness strategy | package-driven false hysteresis |
