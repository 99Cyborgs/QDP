# FORK QUESTIONS

## Trigger Conditions
New Hamiltonian term  
New free parameter  
Primary observable change  
Integrator change  
Platform change  
Scale bridging claim  

## Mandatory Questions

1. What invariant must remain preserved.
2. What known limit must still be recovered.
3. Does this introduce a new free parameter and can it be independently constrained.
4. What observable shows this change is real.
5. What exact result would kill this branch.
6. Does this increase falsifiable surface area or only flexibility.
7. Does this increase numerical fragility.
8. Is there an accessible platform where this observable can be measured.
9. Is this formal core, example, or interpretation.
10. Is any scale claim made without effective mapping.

## Outcome Labels
Proceed  
Sandbox only  
Defer  
Reject  

## Escalation Rule
If more than two new free parameters are introduced at one fork, default to sandbox only until independently constrained.

Bath classification must follow definitions in docs/BATH_GLOSSARY.md.
